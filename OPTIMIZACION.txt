OPTIMIZACIÓN Y CONTROL DEL REDISEÑO

- Se conservaron las imágenes WebP optimizadas del proyecto original.
- Se mantienen width y height en las imágenes de contenido para reducir saltos de layout.
- Se mantiene lazy loading y decodificación asíncrona en imágenes fuera de la portada.
- El video hero y sus recursos exclusivos fueron eliminados para reducir peso y porque ya no forman parte del diseño.
- La navegación por tarjetas utiliza CSS y JavaScript propios, sin agregar frameworks o librerías innecesarias.
- En desktop las tarjetas usan transformaciones; en mobile se usa scroll-snap horizontal para priorizar usabilidad.
- Se conserva el lightbox para las galerías y el comportamiento mailto del formulario.
- Se respeta prefers-reduced-motion para disminuir animaciones cuando el sistema del usuario lo solicita.
